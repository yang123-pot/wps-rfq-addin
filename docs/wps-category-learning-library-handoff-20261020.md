## 分类学习库：已确认的产品设计

### 目标

让用户自己维护简单分类库，并让当前项目已经确认的分类结果沉淀为本机通用学习经验，提高后续项目自动分类的预填准确率。

### 入口与窗口

- 在顶部“材料整理”功能区新增“分类学习库”按钮。
- 打开独立、非模态窗口，可与材料整理助手同时使用。
- 采用独立专用页面，不复用大型 `taskpane.html` 隐藏页面的方式。
- 主界面两个页签：
  - “分类管理”
  - “学习经验”
- “关键词规则”放入默认折叠的“高级设置”。

### 分类管理

- 新增、重命名、归档删除、多选合并。
- “归档式删除”：分类从后续建议中消失，但保留停用记录和历史名称；旧项目继续显示原分类。
- 有关联规则或学习经验的分类不能直接彻底删除，必须先合并到其他分类或明确清理关联数据。
- 合并时由用户选择目标分类，源分类可多选。
- “A 合并到 B”后：
  - A 的名称保留为 B 的分类别名。
  - A 的规则、学习经验、历史确认迁移到 B。
  - 重复规则与相同材料签名去重。
  - A 标记为已归档，并记录 `mergedInto=B`。
- 相似分类只提供候选和理由，绝不自动合并；必须人工确认。
- 相似提示可依据：规范化名称相同、已有别名、名称高度相似且规则/学习材料重叠、历史材料曾落入不同类别。
- 合并默认只影响学习库和后续自动建议。当前已确认项目不变；当前未确认项目可在合并结果页主动勾选“同时应用到当前未完成项目”。

### 学习经验

- 每条经验至少包含：材料名称、项目特征、单位、目标分类、学习时间、来源项目/行摘要。
- 用户可搜索、按分类筛选、撤销一条经验、按分类批量查看。
- 完整来源和历史明细只在学习库窗口按需读取。

### 延迟学习流程

- 不再在整表确认时立即写入长期习惯库。
- 第 7 步拆分完成并校验成功后才显示“是否保存本次分类习惯”。
- 选择“保存”：
  - 从本次整表确认快照读取全部已确认分类。
  - 按“名称＋项目特征＋单位＋类别”去重。
  - 写入本机通用学习库。
- 选择“不保存”：
  - 项目、分类工作簿、询价与拆分成果全部保留。
  - 本次分类不进入长期学习库。
  - 项目保存“已选择不保存”，同一确认版本重开不重复弹窗。
- 保存失败不回滚已经完成的拆分，不把项目显示为拆分失败；保留明确重试入口。
- 学习记录默认适用于本机同一 Windows 用户的所有后续项目，不随项目结束消失。
- 不跨电脑、不跨 Windows 用户、不上云。用户可在学习库中撤销/删除。

### 自动复用强度

- 名称、项目特征、单位完全相同：高优先级复用，可直接预填最终分类。
- 仅名称相同、特征不同：作为相近建议，不绕过人工确认。
- 多条经验给出不同类别：显示冲突并保持最终分类空白。

### 性能硬门槛

当前实际学习库：

- `library-state.json` 约 **13.2 MB**
- 分类 **119**
- 学习经验 **6760**（当前全部 active）
- 历史记录 **10267**

禁止维护窗口一次加载并渲染完整 JSON。必须：

- 服务端分页/筛选；单页建议约 50 条。
- 首屏只取汇总、当前页分类和当前页经验。
- 搜索输入做短防抖，不能每字重算整库。
- 新增、改名、归档、合并、撤销经验在服务端原子提交，并用 `expectedRevision` 防覆盖。
- 自动分类使用压缩分类索引：类别、规则、去重后的材料签名和类别映射；不得每行扫描完整历史明细。
- 维护窗口打开、页签切换、分页、搜索和合并确认均以无长时间阻塞为验收条件；真实 WPS 中做人工操作复测。
