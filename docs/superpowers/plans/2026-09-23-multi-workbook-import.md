# 多工作簿导入与可选合并预览

> 沿用已授权一期设计，使用 executing-plans / TDD 直接实现，完成后复核并提交推送。

**Goal:** 在WPS侧栏选择多个xls/xlsx，先复制后读取，防止重复导入，切换核对各文件并预览可选精确合并。

**Architecture:** 本机资源服务增加带随机会话令牌的复制接口；使用真实规范路径和SHA256识别文件，生成独立工作副本。宿主只读副本并恢复用户活动工作簿。独立collection模块管理导入快照、核对记录和合并选择，侧栏复用现有review/merge接口。

**Spec:** handoff.md下一步第1项、一期设计第二节。当前不实现另存合并工作簿。

## 约束和边界

- GetOpenFilename仅选择路径，不调用打开原件；只从独立副本读取。宏禁用、更新外链关闭，关闭的只能是本次打开的副本。
- 同一规范路径或相同文件字节指纹拒绝重复；多选任一失败时整批不加入，已有文件及核对记录保持不变。每批最多20个文件，每个最多64MiB，总计最多256MiB。
- 文件列表提供切换核对和移除；未保存核对移除前确认。未勾选合并时每条来源独立，勾选后沿用精确三字段与十进制计算。
- 核对快照保留原路径、原文件名及指纹；副本路径单独保留用于定位。恢复记录要求原文件字节及快照一致。当前活动清单的单文件读取与导入集合明确区分，不自动加入集合。
- 预览显示输入/输出数、待核对问题、各来源原编码/原数量/工作表/行及专业。未解决问题仍阻断最终处理，不把预览等同于用户确认或另存。
- 本机副本/manifest仅保存在用户本机应用数据目录（测试在outputs），不通过HTTP作为静态文件提供，不纳入Git。

## Review Focus

- 复制前后原文件被改动，读副本失败或部分成功：不会混入半批或修改原件。
- 同名不同目录、路径别名、内容相同副本：按规范路径和指纹处理。
- 读取过程中宿主失败：恢复宏设置和活动工作簿，不关闭用户工作簿。
- 各文件未保存的核对状态独立，切换不丢失，合并预览反映最新核对及选择。
- 非同源、无令牌、超限请求不能触发本机文件复制；HTTP不泄露原件内容。
