# 安装按钮误禁用与自选安装目录

用户反馈关闭WPS后“一键安装”仍灰色，并批准增加“浏览”选择目录：程序与内置Node/PowerShell保存到选定位置，项目数据独立保存在当前用户目录，升级沿用原位置。以用户所附真实安装器截图和本次批准文字为本包验收依据，不涉及七步业务版式。

实机只读查询发现3个无窗口wps.exe，分别运行jsapibrowser.dll、CefRenderEntryPoint及aspcenter.dll；没有et.exe或文档窗口。旧实现只按进程名计数，将这些后台组件误认为仍在编辑。修正为结合命令行角色及主窗口判定：只放行已知且无窗口的辅助进程，可见窗口、自动化及未知角色仍阻止安装。未结束这些进程。阻止状态每5秒自动复检，并保留手动按钮；正式切换前再查一次。

首次安装可浏览选目录；检查绝对路径、磁盘根目录、数据/来源重叠、写权限及非本插件程序冲突。app/runtime/managers均随所选目录，用户数据的imports/library/projects/headers/splits仍独立保留。installation.json记录程序位置，升级自动读回并锁定；旧安装记录可从app路径推导原位置。目录参数经UTF-8 Base64传递，支持中文及空格。小屏高缩放时窗口限制在工作区内，可滚动触达主按钮。

- 使用官方缓存包的Node22.23.3/PowerShell7.6.7实际安装至隔离的中文空格目录；数据在另一独立目录。无全局PATH的两个manager CLI并发启动均退出0，原位置升级及新服务失败回退通过；代码、安装记录、临时快捷方式、其他插件XML、项目哨兵均保留。只把快捷方式平台边界重定向到临时目录，没有写真实桌面/启动项/注册或安装用户插件。
- 本机原有3个后台组件保持，修正检测ready=true。WinForms共享真实状态渲染显示浏览及绿色主按钮；1366×768工作区/125%受控缩放渲染验证主按钮可滚动触达。缩放渲染不等于另一台机器实测。
