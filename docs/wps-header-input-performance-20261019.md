在独立无头Edge产品页面中，只读恢复实际项目19（960行、38类、预计42份），替代WPS读表边界，不触发保存或导出。对真实产品函数计数和同步事件耗时。

事件链为`header-ui input → onChange → inquiry.refresh + split.refresh + publishAssistant`，其中反复获取内容键和判阶段，又触发清单预览/合并。每个字同步执行整条链会阻塞输入与中文输入法反馈。

## 修正

- `input`立即同步草稿、轻量校验与清除已填字段红框，不重算材料；不改写当前输入内容或移动焦点。
- 同步使简版旧询价/拆分状态失效，并禁用详细版继续拆分及拆分执行按钮，不能在未失焦时沿用旧成果。
- `change`（离开输入框）、应用模板或恢复项目时继续执行完整下游刷新；生成、保存和内容键检查仍读取最新草稿，严格校验保持。
- 表格结构和批准图03四项抬头布局保持。业务文件、项目记录和服务进程未改。
