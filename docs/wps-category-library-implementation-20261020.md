## L4 拆分后延迟学习

整表确认不再发送长期经验保存，确认快照和新类别建库仍保留。自动分类只读取压缩索引；旧客户端全库保存函数已删除，避免压缩数据覆盖完整来源/历史。完全签名经验优先，相近仅建议，多类别经验冲突仍留人工确认。

拆分全部成功并且当前输出核验通过后，显示“保存分类习惯 / 不保存”。保存时服务端重新加载当前已落盘项目、核确认版本、持久化拆分回执、生成键、文件清单和实际SHA；从快照读取全部确认行，含无需询价。一次批量索引去重，保存来源项目名/行摘要，确认键ledger保证响应丢失后重试不重复学习。学习决定绑定inputKey/revision/confirmedAt，随项目保存，重开不再询问；确认变化可重新决定。

学习失败只记录单独可重试状态，不改拆分成功。选择不保存只记录项目决定；若此前保存响应丢失已实际学习，只撤销本确认版本来源，其他项目贡献保留，避免“显示不保存却已学习”。库和项目之间没有跨文件事务：项目决定写回失败时显示明确重试，库端幂等兜底。
