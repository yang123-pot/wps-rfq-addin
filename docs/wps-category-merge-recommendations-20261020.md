# 推荐合并：已确认方案

用户于2026-10-20同意：插件先梳理相似分类，推荐候选，让用户选择保留名称或保持独立。替代必须逐行查找候选的主要入口，原手动合并仍可用。

- 分类管理顶部自动展示“推荐合并”，不增加第三主页签。每页10组，服务端上限50组。
- 每张卡显示双方名称、有效规则/经验数量、最多各2条代表材料、推荐理由。名称相似单独标为需核对，材料重叠/别名等证据充分的排前。
- 支持用户举例“阀门/水阀门”“线缆/电线电缆”；名称本身不作为已证明同类。无需询价、停用/已归档分类不参与。
- 用户选保留A或B后，卡内显示该方向的服务端迁移/去重/别名预览，明确“确认合并”才提交；保留当前未确认项目可选同步，已确认项目保持。
- “保持独立”随库持久保存，不因刷新、重开或其他分类变更反复推荐；双方名称、别名、有效规则或有效材料签名明显变化后允许重新提示。仅新增相同材料的确认来源不重复打扰。
- 服务端按库revision扫描并缓存，磁盘身份变化失效；页面只读当前分页，不返回完整经验、历史或来源。13.2MB完整库不传到页面，不在前端全量渲染。
- 所有修改用expectedRevision；过期卡片、过期预览、切换保留方向的乱序响应不得造成错误合并。“保持独立”也须核候选证据身份。
- 真实库只读，变异回归使用临时合成库。native-01正式验收进度保留，不重置用户已归档临时类。结束恢复F5数据的约定保持。
