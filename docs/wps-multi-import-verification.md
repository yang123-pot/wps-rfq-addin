# 多工作簿导入与合并预览验证

日期：2026-09-23。本轮完成多文件导入、逐文件核对、可选精确合并预览和来源明细；合并清单另存仍是下一项任务。

## 实现行为

- WPS文件选择器只取路径。本机服务解析规范路径、读取原件字节并计算SHA256，再创建独立副本；WPS只打开副本，禁用自动宏、关闭外链更新，读取后关闭本次副本并恢复原活动工作簿及宏设置。
- 同一路径或相同字节内容不重复导入；每批1–20份、每份64MiB以内、总计256MiB以内，会话最多100份。任何一份复制或读取失败，本批均不加入，已有集合及核对保持不变。
- 工作副本使用UUID文件名，避免WPS同时打开同名工作簿的限制；原路径、原文件名、字节指纹和副本路径分别保留。列表和来源明细仍显示原文件身份。
- 导入文件各自保留未保存核对，切换不会丢失。移除未保存文件需确认；关闭前仍提示未保存记录。导入方式与“单独读取当前工作簿”的记录分别保存，互不覆盖。
- 关闭后需重新导入同一原件，再显式恢复本机记录。导入记录绑定原路径、原文件字节指纹及读取快照；文件字节变化时拒绝恢复。导入列表本身尚未持久化。
- 合并选项默认关闭，开启后复用现有三字段精确匹配和十进制累加。预览展示输入/输出条数、阻断问题、全部来源、原编码/核对编码、原工程量/核对量及原表行号；明细和材料列表均分页。预览通过不等于用户确认或已另存。
- 来源定位只打开对应工作副本。来源身份/行列无效时不打开；定位失败时关闭本次新开的副本；已经打开且被修改或可写的副本不能用于定位旧快照，用户工作簿不被关闭。
- 复制接口使用随机会话令牌、严格Host/Origin及JSON请求限制，副本和manifest不通过HTTP静态提供。默认保存在`%LOCALAPPDATA%\WpsRfqAddin\imports`，可用开发参数`--import-directory`指定。当前副本留在本机，尚未提供自动清理功能。

## 验证边界与下一步

本轮真实WPS证据来自COM，**不等于新增JavaScript侧栏全流程验收**。原生多选对话框返回形态、侧栏导入与定位、关闭提示及WPS重启后恢复仍待下一轮实机验收；不能用浏览器合成宿主替代。合并另存、分类、品牌/抬头与询价拆分尚未实现。

导入读取的是选择时已保存的磁盘文件，未保存的WPS编辑不会自动加入。记录保存在同源localStorage，换机器、端口或清理侧栏存储不会迁移。单独读取模式仍只检查路径、表范围和单元格值，不检查文件字节及仅显示格式的变化；数值编码继续要求显式确认显示值和前导零。
