## 修复与验证记录

- 页面删除旧分类/品牌面板；分类库与整表学习服务继续工作，品牌参考单独初始化。
- 成果文件发布校验前显示“待写入”，发布后才显示“已写入”。当前建议与文件状态分别说明。
- 浏览器失败用例发现：新增规则后统计仍为1行建议/1行待核对，新成果也使用旧模型。修复分类库adopt后的流程刷新，测试新增规则、排除条件、停用/启用类别均进入新成果；已有文件和人工确认不被自动修改。
- 浏览器失败用例发现：等待prepare时改变合并选择，会令全局reviewModel变为空并报JavaScript属性错误。现在生成捕获固定模型与内容键，在选择位置、准备、写入、发布校验边界核对当前来源/合并，变化明确拒绝，不绑定错误成果。
- 图01增加文件列表、导入时间、原始/结果行数、完全相同项逐来源数量与精确算式、合并明细。每组结果工程量仅列一次；只写插件新建预览，不保存原件/副本；用户另存或关闭预览后另建，失败明确提示并允许点“查看合并明细”重试。
