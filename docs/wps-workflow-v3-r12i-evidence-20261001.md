## 6. 宿主口径与限制（重要，不作“插件UI真机”解读）

- 值写入与逐值读回走**插件真实代码** `export-host`（真实 `dev/server.cjs` 的
  prepare/commit/verify 发布管线）；分类/汇总/询价/拆分业务模型也全部是插件真实模块。
- **版式落地（列宽/合并/填充/字体/原生链接/数据有效性/打印）改用同一 `layout` 模型的原生
  PowerShell 步骤**（`host/apply-layout.ps1`）。原因：本机在创建 WPS COM 对象后，
  通用 PowerShell COM 桥取回的嵌套子对象（`Range.Validation`）不能再调用，
  `Validation.Add`/`InCellDropdown` 报 `E_INVALIDARG`，且 `New-Object 'object[,]'` 会返回 `$null`
  使二维赋值静默失效；原生调用与用户在 WPS 内直接操作一致。版式结果随后由 openpyxl
  独立读回核对（下拉来源、链接目标、合并、隐藏列、打印区域与重复表头）。
- **插件 UI 内点按仍未执行**（Computer Use 未授权），与 R12-C/D/E/H 的历史缺项一并挂 **R12-J**；
