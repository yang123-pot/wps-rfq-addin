# 无需询价末页回执误报修复（2026-10-19）

## 现象与实测

- 浮窗第4步显示分类工作簿已生成，并称“无需询价”明细位于最后一张工作表。
- 独立读取磁盘文件：实际39页，首页为“分类汇总表”，末页为“传感器”，不存在“无需询价”。
- 项目回执：记录40页，末页为`无需询价`，状态`complete`；缺少`readBack`逐页核验记录。
- 磁盘SHA与项目登记SHA一致，因此不是生成后文件被替换；属于程序跳过写入后错误更新回执。

## 根因

同一路径存在旧版分类工作簿时，生成流程只比较旧回执SHA与磁盘SHA。SHA相同即跳过整本写入，之后却用当前方案重新生成回执，把新增的“无需询价”页标记为成功。新回执覆盖项目记录后，界面只按回执判断完成，未检查实际页结构。

## 修复

- 已完成分类工作簿必须带逐页`readBack`；页名、顺序或行数不一致时不得显示完成。
- 缺少可信`readBack`的旧回执被视为需要重新生成，并阻断分类汇总及后续阶段。
- 复用已有文件时，版式、实际页结构和旧SHA必须同时匹配；否则不跳过写入。
- 不可信已完成回执重新生成时另建成果批次，旧文件保留且不覆盖。

## 验证

- 新增故障复现：项目回执存在，但`readBack`缺失；验证第4步显示“分类工作簿需要重新生成”、汇总按钮保持禁用。
- 重新生成后验证新批次目录、`readBack.ok=true`、逐页数量正确。
- 全量Node **549/549**；全部常规浏览器UI **22/22**。
- 真实WPS旧批次尚未删除，也未替用户重生成；需关闭重开助手加载修复后页面，再按项目提示生成新批次。
