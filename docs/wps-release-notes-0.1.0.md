# 材料整理助手 0.1.0 发布说明

构建：`20261020-R1`

支持环境：Windows、WPS 表格 `12.1.0.29161`

当前状态：候选已构建；完成真实 WPS 最终回归后正式发布

## 主要功能

- 从 WPS 功能区打开材料整理助手，按七步完成清单导入、自动分类、表内审核、分类工作簿、品牌供应商、总询价和一键拆分。
- 导入预览按原工作表顺序显示目录统计，并保留全部来源表原样副本；默认逐条保留，勾选“合并清单”才按名称、项目特征描述、单位精确合并并累加工程量。
- 未合并清单时，为每份来源工作簿生成原表审核副本，保留工作表顺序、小标题、合并区和格式，仅追加审核列；合并清单时使用统一审核成果表。
- 分类冲突按同一材料最近学习经验、冲突类别最近经验、候选顺序预填，保持橙色警示并要求整表一次确认。
- 分类学习库为独立非模态窗口，支持分类维护、归档限制、人工合并预览、学习经验分页和撤销；只有拆分全部核验后才一次性保存本次确认分类。
- 分类工作簿为一本多页：首页分类汇总，其后每类一页，最后保留“无需询价”页。
- 品牌、供应商和询价生成方式在分类汇总表内填写；品牌和供应商允许留空，多组仍须选择生成方式。
- 总询价表前五行为公司/询价、地址与联系人、电话/传真/邮箱、供货单位、工程名称；材料表头固定第6行，公开10列，报价单价和金额留空。
- 第7步输出供应商文件、无需询价文件和拆分前完整总表，逐份核对 SHA，支持失败续作和外部修改待核对。
- 项目、分类库、抬头模板和拆分回执保存在本机，默认卸载保留。

## 本轮修正

- 第5步“打开汇总表”直接定位分类汇总页和首组品牌格，避免停在工作簿上次使用的其他页。
- 已打开另一目录同名工作簿时，集中提示明确要求保存关闭后重试，避免误导更换输出目录或另存。

- 修复预览与项目恢复并发核验时，只读文件核验被写入锁错误拒绝的问题；写操作仍保持互斥。
- 文件核验请求失败时保留会话失效、服务忙碌或读取失败原因，避免误报来源变化并要求重导入。

- 修复从安装包升级后缺少 `library.html`、`library.css`、独立学习库无法打开的问题。
- 修复 WPS 已打开另一目录同名分类工作簿时误激活或借用该对象的问题，改为明确提示先关闭同名簿。
- 同名保护同时覆盖第5步汇总表打开、进入填写及读回；普通路径中的字面 `%xx` 不会被误当作另一目录。
- 修复简版误选文件后缺少“移除此文件”入口、合并选择时未显示 `10→8` 结果、同名工作簿打开失败未显示具体原因的问题。
- 修正文档中冲突留空、分别保留生成扁平成果、品牌必须填写、旧五项拆分和旧构建号等过时说明。
- 更新用户说明截图和逐文件安装清单。

## 已知限制

- 只支持并实测 WPS 表格 `12.1.0.29161`；其他版本未验证。
- 历史 32 类/旧词表批量迁入不在本版自动执行；需要单独业务确认和迁移验收。
- 浮窗默认位置、精确原生像素宽度/缩放和长期稳定性仍以真实 WPS 最终回归结论为准。
- 本机学习经验不跨电脑、用户或云端同步。
- 插件只生成本地文件，不自动通过微信、邮件或其他渠道发送。
