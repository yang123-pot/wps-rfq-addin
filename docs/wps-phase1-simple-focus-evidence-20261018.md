# 材料整理助手简版单步流程证据（2026-10-18）

工作包：默认简版去除普通用户不需要的技术信息，并把七步业务串成连续操作。对应效果图为 `docs/mockups/approved-20261017-ui-simplify/01-current-step.png`，补充口径见 `docs/mockups/approved-20261017-ui-simplify/amendments-20261018.md`。

## 1. 用户要求

- 识别预览、材料编码、来源路径、行号定位、“核对/修正此行”等技术信息，普通材料员看不懂也无需在默认窗口看到。
- 其他步骤采用同样口径。
- 操作要有连贯性：完成一步后，在同一位置显示下一步按钮。

## 2. 实现

- 简版不再进入底层技术面板；操作按钮仍复用现有业务函数，但用户始终停留在“当前这一步”卡片。
- 第1步导入后直接显示“分别保留／合并完全相同项”两个通俗选项和处理摘要，确认后才显示下一步。
- 每一步完成后按真实阶段状态在原主按钮位置显示下一操作，例如“生成审核成果表”“打开成果表核对”“确认并生成分类工作簿”。
- 七步列表改为只显示进度，不再点入技术页面。
- 简版隐藏：识别预览、文件路径、逐文件识别统计、核对/定位、合并明细、阶段进度条、技术状态说明、布局选择、文件/问题明细、重试和重建入口。
- 详细模式保留全部原功能，供排障和高级操作使用。
- 修复拆分页“尚未选择输出目录”文字被误判为已选择目录、导致提前显示“一键拆分”的问题。
