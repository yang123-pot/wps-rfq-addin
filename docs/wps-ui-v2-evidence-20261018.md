## 已实现

- 功能区五入口：选择清单、填写品牌、生成文件、打开项目、帮助；设置保留项目、分类库、品牌参考、抬头模板、内部导出和详细排障。
- 紧凑七步、默认400px操作区布局、内容独立滚动及底部固定主按钮；每步完成原位显示下一动作。第6步直接填写四项必填抬头，详细模式仍可编辑同一份内容。
- 新增显式界面状态及可等待动作，移除读取提示文字猜进度的逻辑。重复点击受锁保护，执行期间设置内的业务按钮一并禁用。合并工作簿与累加相同材料独立选择，恢复不再将两者混为一项。
- 导入预览确认、自动分类、整表审核、一本分类簿、汇总表品牌读回、总询价和拆分接通。取消保留内容，失败维持门槛；已生成但绑定未保存时只重试保存。拆分显示真实文件、部分失败续作和待核对入口。
- 统一错误弹窗：问题、具体位置、修改方法和处理按钮；支持成果表单元格定位与抬头聚焦。多问题集中，关闭保留摘要，未知异常保留详情。抬头填好后立即去除红框。
- 沿用项目v2、本机服务API及现有业务模型。品牌仍只从汇总表读回，没有增加侧栏逐行审核或品牌二次确认；精度、追溯、内容校验、冻结、打印、失败续作与恢复断言保留。

## 独立审查及修复

一次独立只读审查发现并在本轮先复现失败、再验证通过：

1. 新分类簿保存失败时，误用旧已保存分类回执解锁。现比较本次路径、SHA、输入键及审核版本，并给出保存重试。
2. 首页恢复状态没有使用持久文件审计门槛。现使用项目UI的实时评估，所有下游状态继承上游阻断。
3. 汇总绑定保存失败后再次点击绕过保存。现明确要求相同持久绑定，第5步另有保存门槛。
4. 第6步抬头移入首页后详细设置不可见。现按显示模式移动同一节点，填写内容保留。
5. 布局下拉显示旧值可能导致选错输出布局，按功能影响处理：状态发布并同步恢复值，双布局原断言保留。

作者同时修复帮助入口显示在隐藏容器、预览失败无原位重试、填写后红框不消失。未因审查改动原有分类及输出业务规则。
