# 多工作簿统一项目与重复材料处理口径（2026-10-18，用户确认）

本说明与图01共同使用，原PNG不重绘。

用户明确：一次导入对应一个项目；多个工作簿默认归入该项目的同一份材料清单和审核成果。图01中的材料处理选项只决定是否累加完全相同的材料，不再表示“合并工作簿”或“拆分多个项目”。

- “分别保留（按工作簿分组）”是默认选项：全部材料行进入当前项目，不累加重复项，并保留每项来源的工作簿、工作表和来源行。
- “合并完全相同项”：仅项目名称、项目特征描述、单位完全一致时精确累加数量；不模糊匹配，不换算单位，所有工作簿仍属于当前项目。
- 多工作簿导入后，侧栏和导入预览必须明确显示“当前项目只生成一份审核成果”，避免把重复项处理与工作簿归属混为一个选择。
- 来源或处理方式变化后，原确认失效，需要重新确认；原件和导入副本的处理规则不变。
