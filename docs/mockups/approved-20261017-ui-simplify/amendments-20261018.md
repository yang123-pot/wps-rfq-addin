# 简版单步流程补充说明（2026-10-18，用户确认）

本说明补充默认简版和现有效果图，原 PNG 不重绘。

- 默认界面始终停留在“当前这一步”卡片，不再在操作后展开识别预览、入口列表、进度统计、问题定位等技术面板。
- 每一步完成后，在原主按钮位置直接出现下一步操作。
- 导入完成后先生成只列工作簿和工作表的预览，不产生材料合并结果；用户看过预览后，才显示“是否合并全部工作簿”，再选择是否累加完全相同材料。
- 用户选择导入文件后继续显示文件名和结果摘要；编码、工作表识别明细、来源路径、行定位、修正展开项、候选统计、批次/回执等内容只在“详细步骤”保留。
- 品牌、询价和拆分步骤同样只显示当前需要做的操作，不在简版重复展示技术状态。
- 七步列表作为进度展示，不再点击跳入技术页面；需要完整功能时使用右上角“详细步骤”。
