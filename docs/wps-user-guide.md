# WPS询价插件一期使用说明（2026-09-27）

插件按七步主流程执行：导入与合并 → 自动分类 → 表内审核 → 分类工作簿 → 品牌汇总 → 询价表 → 拆分文件。每一步只有真实文件或绑定核对通过后才会显示“已确认”；上游内容变化会让下游显示“已过期”，不会沿用旧结果。

## 1. 导入与合并

1. 在“项目询价”功能区打开侧栏，进入第1步“导入与合并”。
2. 优先用“浏览本机文件并导入（推荐）”，在侧栏内选择和目录，不弹系统对话框。
3. 原件只被复制读取，原文件不会打开或改写。重复内容按SHA256拒绝。
4. 默认“分别保留清单”。只有勾选“合并完全相同项”才按“项目名称＋项目特征描述＋单位”精确合并；不模糊匹配、不换算单位。
5. 核对来源问题后点“确认选择，开始自动分类”。不合并也必须确认一次。

## 2. 自动分类

1. 确认合并选择后，插件按分类库和习惯记忆生成建议，生成独立“项目名_分类审核成果.xlsx”。
2. 唯一可靠建议会预填“最终分类”，冲突或无建议的行留空并突出显示。
3. “自动匹配完成”只表示建议已生成，仍显示“尚未人工确认”。
4. 点“打开成果表审核”进入WPS表格内审核；不要在侧栏逐行确认。

## 3. 表内审核与整表确认

1. 在成果表内直接修改“最终分类”和“审核备注”。最终分类是浅黄下拉列，可填有效类别或“无需询价”。
2. “保存审核成果”只保存草稿，不确认、不学习、不生成分类工作簿。
3. 全部修改完成后回侧栏点“审核完成，生成分类工作簿”。插件按稳定行标识整表读回一次校验；空分类、未知分类、缺行、重复行或固定字段改动会定位到具体单元格并阻断。
4. 整表确认快照先保存，再学习和生成分类工作簿。重复点击幂等；改确认只撤销被改行的学习来源。

## 4. 分类工作簿

1. 每个询价类别生成一个独立 `.xlsx`，不是同一工作簿里的多个工作表。
2. 每份“材料明细”包含10列：序号、项目编码、项目名称、项目特征描述、单位、工程量、品牌、报价单价、金额、备注；此时品牌、报价、金额为空。
3. 无需询价行只保留在审核成果表中。
4. 全部文件重开核对并记录SHA后才解锁“生成分类汇总表”；局部成功不会显示全部完成。
5. 重新确认分类会生成新批次，不覆盖旧批次。

## 5. 品牌汇总

1. 在“分类汇总表”中按类别填写品牌和供应商。汇总表支持两种布局：
   - 分列：每组品牌、供应商各一列。
   - 同格：每个单元格两行填写“品牌：…”和“供应商：…”。
2. 一类一行，最多3组品牌/供应商；未使用组留空。多个品牌要让用户选择“合成一份”或“按品牌分别生成”。
3. 类别名称是蓝色下划线链接，指向对应独立分类工作簿。
4. 填完回侧栏点“填写完成，生成询价表”。插件读取最新汇总表、校验并保存；侧栏不逐行编辑品牌，也不二次确认。
5. 改品牌、供应商或生成方式会让旧询价表/拆分文件过期；旧文件保留，需重新生成。

## 6. 询价表

1. 先在“辅助功能 → 询价抬头”填写项目名称、单位名称、材料经办人、联系方式；原公司地址可选。
2. 第6步按汇总表选择的方式生成总询价工作簿：
   - “按品牌分别生成”：每组一张询价表，每张包含本类全部材料。
   - “合成一份”：同表列出全部品牌和供应商，材料行及工程量只出现一次。
3. 对供应商公开的材料仍是10列；报价单价和金额留空，不带原价或历史报价。
4. 总询价工作簿含内部追溯/处理记录页；拆分时不会把这些内部页外发。
5. 点“下一步：拆分询价文件”进入第7步；改品牌或抬头需回汇总表修改并重新生成。

## 7. 一键拆分

1. 选择输出文件夹，点“一键拆分询价文件”。每张询价表生成一个独立 `.xlsx`。
2. 文件名为“类别_供应商名称.xlsx”；多供应商合成使用“类别_多供应商.xlsx”。
3. 已有同名文件绝不覆盖；拆前会核对总询价工作簿SHA、内容键、输出目录和全部目标。
4. 结果窗口逐份显示成功/失败/待核对；失败可只重试未完成项。已成功文件按SHA跳过，不重复写入。
5. 服务重启后仍按项目＋批次回执续作；外部改写已成功文件会标“待核对”，不覆盖。
6. “打开输出文件夹”指向实际输出目录。

## 项目保存、重开与外部修改

- “保存项目”保存来源、合并选择、审核草稿/确认、分类清单、汇总绑定、总询价生成记录和拆分回执。
- 重开项目时先核对每个阶段的真实路径和SHA。文件缺失、外部改写、拆分未完成或未知版本不会恢复为“已确认”。
- 如果成果目录整体搬移，可在项目状态里点“重新定位项目文件”，选择搬移后的成果根目录。插件按原相对结构重写绑定，并再次逐项核对内容后才保存。
- 来源原件变化时不会沿用旧副本；会提示重新导入。原件本身不会被修改。

## 数据位置

- 项目：`%LOCALAPPDATA%\WpsRfqAddin\projects`
- 分类库与习惯：`%LOCALAPPDATA%\WpsRfqAddin\library`
- 抬头模板：`%LOCALAPPDATA%\WpsRfqAddin\headers`
- 导入副本：`%LOCALAPPDATA%\WpsRfqAddin\imports`
- 拆分回执：`%LOCALAPPDATA%\WpsRfqAddin\splits`

卸载默认保留以上数据；整机迁移可复制整个 `WpsRfqAddin` 目录。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 模块显示未完成 | 查看阶段原因，通常是上游来源/合并/审核变化或持久文件未核对通过 |
| 模块显示已过期 | 回到最早变化的阶段重做，旧文件仍保留，不会覆盖 |
| 分类或品牌表读回失败 | 按提示的工作表与单元格修改；固定列和行标识不要改动 |
| 询价生成按钮不可用 | 检查品牌是否已读回、抬头四项是否完整、汇总表是否已变化 |
| 拆分被阻断 | 看总询价簿SHA、输出目录、已有目标或待核对文件提示 |
| 重开项目提示文件缺失 | 先看原路径；若只是整目录搬移，用“重新定位项目文件”选择新根目录 |
| 侧栏停止刷新 | 先保存可保存内容，再点功能区“项目询价 → 侧栏停住时重建”；仍无效再重启WPS |
