# WPS询价插件一期使用说明（2026-09-26）

侧栏按“导入→核对→合并预览→分类→品牌→生成→拆分”的顺序走。每一步都只在前一步真正完成（不是只填了字段）之后才允许继续；侧栏“项目状态”会显示每个阶段是已确认、已过期还是未完成，并给出原因。

## 一、导入与核对

1. 打开插件侧栏，点“选择清单文件导入”。插件先**复制**原件再读取，原文件不会被打开或改写。
2. 同一份文件重复导入会被拒绝（按内容SHA256判断），不是只比文件名。
3. 在“来源核对”里逐项处理问题：缺少编码/单位/名称、工程量异常、来源待核对、特征续行等。全部问题清零后来源核对才会显示已确认。
4. 核对记录保存在本机侧栏，换工作簿或改文件后会失效并提示，需要重新核对。

## 二、合并预览与确认

1. 默认“按来源分别保留”；勾选后只做**名称＋项目特征描述＋单位完全相同**的精确合并，不做单位换算，也不按编码强合并。
2. 预览通过后必须点“确认本次合并预览”——**不合并也要确认一次**。之后才能继续分类和生成。
3. 改了来源文件或合并方式，之前的确认会自动失效，需要重新确认（侧栏会提示）。

## 三、分类核对与分类库

1. 每一行都要人工确认类别或“无需询价”；建议与习惯记忆只是建议，不会代替人工确认。全部确认后才允许写入或生成。
2. 写入时可选择写工作副本或已另存的合并清单；已有内容的单元格不会被覆盖，会报告实际完成多少行。
3. “分类库与习惯”面板可以增改类别、规则关键词、别名、排除条件与依据；保存是原子的，版本冲突会提示重新加载而不是覆盖。人工确认成功后会把材料→类别记成本机习惯，撤销确认只失效本次来源。

## 四、品牌与供应商（按确认后的做法）

1. 分类完成后，插件按类别自动生成“分类品牌表”汇总表：**一个类别一行，品牌列留空**，人工只需要填品牌（供应商、备注可留到后面再补）。
2. 点“生成分类品牌表”，选择一个新路径（不覆盖已有文件）。文件含三张表：`分类品牌表`（填写区）、`材料明细`（逐条材料与来源）、`填写说明`（填写范围与品牌联动规则）。
3. 在WPS里**只填品牌/供应商/备注三列**。分配标识、类别、材料条目数、材料行标识是固定列，改动后读取会指出具体行并拒绝。
4. 回到侧栏点“读取并核对品牌表”，先看逐项预览，确认后才写入项目；读取失败不会改动项目里已有的品牌。
5. **品牌联动**：汇总表里填的品牌是询价表与拆分文件品牌列的唯一来源，不要在询价表里另行填写或改写。
6. 同一类别要多品牌时，点“新增品牌行”拆成多行，并勾选每行覆盖的材料；此时需要选择“同类别多品牌口径”。

## 五、抬头

抬头字段：公司名称、公司地址、联系方式、工程名称、材料员。插件不会预填任何真实信息；模板保存在本机独立文件里，修改模板不影响已保存项目。

## 六、生成与拆分

生成得到对供应商的询价工作簿：每个品牌行一张询价页，表头为序号、项目编码、项目名称、项目特征描述、单位、工程量、品牌、报价单价、金额、备注；**报价单价与金额留空**，原价与历史报价不带入。工作簿另含内部追溯页与处理记录页，拆分时不会外发。

拆分把一个询价页输出成一个文件，基础文件名是`分类_供应商名称.xlsx`；重名、路径过长、目标已存在都会在发布前阻断，绝不覆盖。中途失败或重启后可以按回执继续，只重做未完成的文件。

## 七、数据位置与备份

- 项目：`%LOCALAPPDATA%\WpsRfqAddin\projects`
- 分类库与习惯：`%LOCALAPPDATA%\WpsRfqAddin\library\library-state.json`
- 抬头模板：`%LOCALAPPDATA%\WpsRfqAddin\headers\header-templates.json`
- 导入副本：`%LOCALAPPDATA%\WpsRfqAddin\imports`

卸载不会删除以上数据。整机迁移时复制整个`WpsRfqAddin`目录即可。

## 八、常见问题

| 现象 | 处理 |
| --- | --- |
| 合并确认一直是未完成 | 回到合并预览点“确认本次合并预览”；改了来源或合并方式后需要重新确认 |
| 分类确认显示未完成 | 检查是否还有未确认的行（筛选“待确认”），或上游来源核对是否过期 |
| 品牌阶段未确认 | 汇总表每行都要填品牌；填完点“读取并核对品牌表”并确认预览 |
| 生成按钮不可用 | 检查是否还有待核对问题、品牌是否已读回、是否已选输出目录 |
| 拆分被阻断 | 看冲突提示：目标已存在、文件名重复、路径过长或总工作簿已过期 |
| 写入报“已有内容” | 目标单元格里有内容，插件不会覆盖；换新文件名或清理目标列后重试 |
