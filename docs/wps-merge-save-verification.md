## 已知边界与未完成项

- **合并模式实机另存尚未取得证据。** 当前WPS构建下，侧栏在导入完成后对滚动、缩放、`End`/`Ctrl+End` 等合成输入不响应，导出按钮位于折叠区域之外，无法可靠点击；因此“勾选合并→3→2→水管0.3”只有模型与浏览器合成宿主的证据，没有真实WPS输出文件。
- 同一环境下功能区展开/收起会使侧栏内容整体上下漂移约30像素，按截图坐标点击容易落空。复测时应先即时截图再点击，或改用键盘焦点（点击侧栏空白处后 `Tab`+`Enter` 触发按钮，本次据此成功触发导入）。
- 尚未在真实WPS验证：另存确认取消、保存位置取消、目标已存在、写入/提交失败提示、数值编码显示格式（`000000`）失效关系。这些均有自动化覆盖，但不等同实机结论。
- 真实WPS侧栏首次导入曾出现“prepared已生成但界面无变化”；本次经诊断日志确认同一批次导入逻辑全部走通，界面未刷新与侧栏重绘/捕获异常有关，未定位到产品逻辑缺陷，也未修复。
