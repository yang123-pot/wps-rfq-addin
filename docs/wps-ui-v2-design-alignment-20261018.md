# 新版界面与获批效果图对齐记录（2026-10-18）

本轮实际对照 `docs/mockups/approved-20261018-wps-ui-v2/01-import-preview.png`、`02-workflow-first-half.png`、`03-workflow-second-half.png`。浮窗外壳按用户授权保持独立窗口，页面内容按图对齐。

## 已修改

- 页头只保留“材料整理助手”、当前项目名和齿轮入口；独立图标与“详细步骤”按钮不再占据页头，详细流程仍可从设置进入。
- 七步进度改为效果图的单行七列短标签：选择清单、分类、核对、工作簿、填品牌、询价表、拆分；步骤数居中显示在进度下方，完成页显示“全部完成”并将七个编号圆点统一填绿。
- 第 1 步预览后收起文件树，只保留合并方式；合并工作表的选择与重复材料累加继续独立控制。导入结果改为普通文字，补“原始文件不会修改”说明。
- 第 2 步改为“自动分类完成”，材料总数、待填写数和下一步说明分三行显示。
- 第 3 步按图显示待填写数量；读取校验完成后显示“8 条材料已填写完整”的绿色结论。黄色单元格定位、整表确认和大面积错误弹窗不变。
- 第 4 步主界面不再显示布局下拉；双布局仍在详细设置中保留。补“首页是汇总表，每类材料一张工作表”的说明。
- 第 5 步拆分为“每类至少填一组”和“可再填写第三组”两段提示；预计份数只在读回真实品牌组合后显示。
- 第 6 步四项必填抬头改为左侧标签、右侧输入框；可选地址和模板控件收进详细设置。任何步骤切换后内容区回到顶部，避免成功状态被滚动位置遮住。
- 第 7 步标题改为“生成供应商文件”，目录改为卡片式展示；选择目录后直接列出实际计划的 5 个供应商文件与 1 个完整总表，固定主按钮原位切换为“开始拆分”。
- 完成页显示 6 个实际文件及绿色勾选，保留“再整理一份清单”和“打开文件夹”。
- 返回入口会切到上一步的详细核对视图，不改变已完成的业务数据。
