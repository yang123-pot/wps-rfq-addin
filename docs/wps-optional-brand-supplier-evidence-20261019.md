# 品牌和供应商允许留空（2026-10-19）

## 规则

- 第5步汇总表的品牌、供应商均为可选。
- 全部留空、只填品牌、只填供应商都可以读回并进入第6步。
- 空值不补造、不继承其他类别；询价表对应品牌列和供应商信息区保持空白。
- 多组品牌仍必须选择“合成一份”或“按品牌分别生成”。
- 供应商为空时，拆分文件名退回只使用类别名。

## 实现

- 汇总表读回取消 `group-empty` / `group-half` 阻断；未知文本、重复组合和生成方式缺失仍报单元格。
- 询价模型为无品牌组类别生成一个占位空组：保留该类完整材料行，品牌与供应商值为空。
- 空品牌页名使用类别名；空供应商拆分名使用类别名。
- 第5步主按钮改为“读取汇总表，下一步”，界面明确允许留空。
