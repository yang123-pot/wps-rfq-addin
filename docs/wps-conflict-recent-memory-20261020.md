# 分类冲突按最近学习经验预填

用户2026-10-20指出：有分类冲突时，插件应根据本机学习经验给出一个可选分类，可按最近经验的分类名称预填，并用不同颜色提示核对，不能直接留空。

## 规则

- 冲突仍保留“分类冲突”状态、异常行橙色和整表一次确认，不把预填当成人工确认。
- 预填优先级：
  1. 同一材料在冲突类别中的最近有效经验（完全匹配优先，其次同名相近）。
  2. 冲突类别自身最近的有效经验；仅使用本机全局或当前项目可见记录，不串其他项目。
  3. 两边都没有经验时，按自动分类候选顺序取第一个，明确写“暂无同类学习经验”。
- 最终分类单元格额外使用警示色`#F4B183`；审核备注自动写“分类冲突：已按最近学习经验预填，请核对”或“暂无同类学习经验，已按候选顺序预填，请核对”。
- 自动建议列继续显示“待核对”，避免把冲突伪装成普通“匹配成功”；公开的最终分类可以立即编辑或改选。
- 整表确认仍保存所有行；用户清空预填后仍按“最终分类为空”定位并阻断。
