# WPS招标清单询价插件

将整个项目的招标清单分类、核对，生成面向供应商的独立询价文件。

**当前阶段：正式开发，WPS功能区、侧栏、工作簿读取和另存已实机验证，业务分类与文件拆分尚未实现。**

流程：WPS打开清单 → 用户选择是否合并多个工作簿 → 自动备注材料类别 → 全部人工确认 → 单独填写品牌和供应商 → 带入询价抬头生成工作表 → 一键拆分为“分类_供应商名称.xlsx”。

第一期只整理和生成文件，由用户自行发送；微信和邮件发送留待下期。
